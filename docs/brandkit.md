# Lumio — Brand Kit

> **Positioning line:** AI language learning that feels like turning on a light.
> **Tagline:** *Light up a new language.*

A polished, playful identity system for an AI-powered language learning app. Warm enough to feel like a friend, refined enough to feel like a real product.

---

## 1. Brand Strategy

| Dimension | Decision |
|---|---|
| **Category** | Gamified, AI-tutored language learning (mobile-first) |
| **Audience** | 18–35 self-directed learners; busy adults who want a few minutes of daily, joyful practice |
| **Personality** | Warm · Curious · Encouraging · Smart · Never condescending |
| **Emotional promise** | "You can do this, and it feels good" — mastery through daily, low-pressure habit |
| **Core metaphor** | **Light + Conversation.** Understanding ignites speech. Every word learned is a small spark that lets you connect with another person and culture. |
| **Cultural position** | Duolingo's friendliness, minus the guilt-tripping; a calmer, more premium "learn-to-glow" alternative |
| **What to avoid** | Green-owl clone marks, fear-mongering streaks, corporate ed-tech grayness, AI-robot clichés |

**Why the system is ownable:** the name *Lumio* fuses *lumen* (light) and *lingua* (language). Every brand decision — the spark-in-bubble mark, the warm ember accents, the tagline — repeats that single idea. One metaphor, repeated consistently.

---

## 2. Logo Concept

### The Spark-Bubble "L"

The mark is an **"L" built from a speech bubble and a flame** — the two halves of the brand idea fused into one reduced glyph.

- **Vertical stem** = a rounded speech-bubble outline → *conversation*
- **Horizontal base** = a soft flame/ember tongue → *light / understanding*
- The bubble and flame share one continuous stroke, so the mark reads as a single letter, not a collage.

```
   ██████
   ██    ██      rounded speech bubble
   ██    ██      (conversation)
   ██    ██
   ██  ██████████████
   ██  ██████        flame tongue
   ██  ██████        (light / understanding)
```

**Construction rules**

- Drawn on a strict 8×8 modular grid.
- The bubble is two overlapping circles (Ø4 and Ø5) plus a square tail; the flame is a teardrop curve tangent to the base.
- Corner radii: 36% of stroke height on the bubble; the flame ends in a single continuous curve — never sharp, never jagged.
- The flame reads as part of the "L" at small sizes; at app-icon size it reads as a warm spark.

**Lockups** (always the same proportions)

1. **Icon only** — used as avatar, tab icon, notifications, favicon.
2. **Horizontal** — icon + wordmark, optical-height aligned. Primary lockup for marketing.
3. **Stacked** — icon above wordmark. Used for launch screens, certificates, print.
4. **Badge** — icon inside a rounded-squircle tile with the ember gradient. App icon, splash, social avatar.

**Wordmark**

- "Lumio" in the display typeface (Fredoka / Baloo 2), letterspaced to +2%.
- The **"i" dot is replaced by the flame spark** (small ember disc) in color lockups; monochrome versions use a plain dot.

**Clearance & sizes**

- Minimum clear space = height of the "L" × 0.5 on all sides.
- Minimum icon size: 24 px; minimum horizontal lockup width: 120 px.

## 3. Color System

One dominant system, warm-light on a deep-ink canvas. One accent carries the brand; the rest support.

| Token | Hex | Role | Usage ratio |
|---|---|---|---|
| **Ink (Deep Indigo)** | `#241B4A` | Primary brand color; dark surfaces, headers, text on light | 40% |
| **Lumio Coral** | `#FF6B57` | Primary accent; CTAs, active states, the flame/spark | 20% |
| **Daylight Amber** | `#FFB74D` | Secondary accent; XP, streaks, celebration, warm fills | 15% |
| **Mint** | `#35D0A0` | Success; correct answers, completed lessons, checkmarks | 10% |
| **Lavender Mist** | `#EAE6FF` | Soft light surface; cards on dark, tinted backgrounds | 8% |
| **Cream** | `#FFFBF4` | Canvas for light-mode screens and print | 5% |
| **Slate** | `#5E5A80` | Secondary text, captions, disabled states | 2% |

**Rules**

- Coral is the single *brand* accent — it never loses to another color in a CTA.
- Amber is always the reward color (XP / streak), mint always the correct-answer color. Do not swap their jobs.
- Gradient (brand, dark→light): `#241B4A → #4B3FA8` for surfaces; ember gradient `#FFB74D → #FF6B57` reserved for the spark, app icon, and celebrations only.
- Text on Ink = Cream; text on Cream = Ink; text on Coral/Amber = Ink.

## 4. Typography

Two families, one display voice.

| Role | Family | Notes |
|---|---|---|
| **Display / Wordmark** | **Fredoka** (or Baloo 2) | Rounded, friendly, warm. Used for headings, the wordmark, mascot speech, big numbers. Weights 500–700. |
| **UI / Body** | **Inter** (or Plus Jakarta Sans) | Clean, humanist, highly legible at small sizes. Weights 400–700. |
| **Numbers (optional)** | Inter tabular numerals | For XP and streak counters so digits don't jump while animating. |

**Scale (mobile)**

| Token | Size / Weight |
|---|---|
| Display | 32 / 700 |
| Title | 24 / 700 |
| Body | 16 / 400 |
| Caption | 13 / 500 |
| Micro-label | 11 / 600, +4% letter-spacing, uppercase |

**Rules**

- Display is reserved for joy: headlines, rewards, the wordmark. Never for body copy.
- Rounded corners everywhere (see §6) mirror the Fredoka letterforms; type and UI feel like one family.

---

## 5. Voice & Tagline

**Tagline:** *Light up a new language.*

**Micro-copy voice**

- Encouraging, specific, warm: *"You just learned 8 words about food. That's a spark."*
- Never guilt-based, never threatening streaks, never condescending.
- Celebrations are understated-premium, not confetti-explosion (unless the user earned it big).

---

## 6. Visual Language

- **Shape system:** rounded-squircle cards, 24px corner radius on large surfaces, 12px on chips. Buttons fully rounded (pill).
- **Iconography:** one weight (outline at rest, filled on active), consistent 2px stroke, rounded caps. Spark icon reserved for "learning completed" and AI moments.
- **Image direction:** warm, candid, human moments — people laughing mid-conversation, golden-hour natural light, soft lens flare that echoes the spark. Never generic stock handshakes.
- **Texture:** very subtle paper grain on light surfaces; faint sparkle dust in celebration moments only.
- **Motion:** soft, 200–300ms easing; light blooms (not bounces) for rewards. The spark "ignites" on lesson completion.

---

## 7. Applications

- **App icon:** Spark-Bubble L badge on the ember gradient (`#FFB74D → #FF6B57`), cream spark. Rounded-squircle.
- **Splash:** Ink background, centered badge + wordmark, one ember gradient line.
- **Lesson UI:** Ink header, coral CTA ("Continue"), amber progress bar, mint correct-flash, cream lesson cards on Lavender Mist.
- **Streak / XP chip:** amber flame glyph + Inter tabular number.
- **AI tutor moment:** spark icon pulses softly beside tutor speech.
- **Empty states:** mascot-free, warm illustration of the spark with one encouraging line.
- **Pattern tile:** repeat of the bubble outline at 12% opacity on Ink for marketing backdrops.
- **Business card / print:** Cream stock, Ink type, coral spark on the reverse.

---

## 8. Anti-Brand Rules

- No green owl, no bird mascot, no "daily reminder" guilt.
- No blue-gradient AI clichés, no robot faces.
- No more than 3 colors per screen.
- No sharp corners, no heavy shadows, no 3D bevel.
- Never render the wordmark in monospace or all-caps.
